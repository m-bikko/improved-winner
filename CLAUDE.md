# Тандем

Приватное PWA на двоих: темы для обсуждения, задачи, дневник питания, база
продуктов. Стек и команды - в `README.md`.

Название приложения настраивается сборкой (`VITE_PUBLIC_APP_NAME`) и живёт
в `src/lib/appName.ts`. Вписывать его в новый код строкой не нужно.

## Wiki (База знаний)

В проекте есть LLM-поддерживаемая база знаний в `wiki/`.

**При любых вопросах о проекте:**
1. Сначала прочитай `wiki/index.md` - найди релевантные страницы.
2. Прочитай нужные страницы из `wiki/pages/`.
3. Отвечай, опираясь на вики. Если информации нет - ищи в коде и обновляй вики.

**При изменениях в проекте:**
- Если изменение затрагивает архитектуру, модели данных, интеграции или важные
  концепции - обнови соответствующие страницы в `wiki/pages/`.
- Обнови `wiki/index.md`, если создана новая страница.
- Добавь запись в `wiki/log.md` (дата, тип операции, затронутые страницы).

**Схема вики:** `wiki/CLAUDE.md`

## Правила, специфичные для этого проекта

**Миграции - только через `pnpm db:push`.** Инструменты `mcp__supabase__*`
здесь не использовать: MCP-сервер может быть привязан к другому проекту,
а CLI авторизован под другим аккаунтом. Цель задаётся явно строкой подключения
из `.env`. Подробности - `wiki/pages/concepts/deployment.md`.

**Инварианты держит база, а не форма.** Всё, что должно быть правдой всегда,
выражается ограничением в схеме. После изменения схемы прогонять
`npx tsx scripts/check-schema.ts` - там каждый кейс обязан упасть.

**После изменения схемы** - `pnpm db:types`, чтобы `src/types/db.ts` не разошёлся
с базой.

**Данные в кэше TanStack Query обязаны переживать JSON.** `Map`, `Set` и `Date`
туда класть нельзя. При несовместимом изменении формы поднимать `CACHE_BUSTER`
в `src/lib/queryClient.ts`.

**Базовые CSS-сбросы только внутри `@layer base`.** Неслоёные правила побеждают
утилиты Tailwind в каскаде.

**Перед коммитом - `pnpm build`, а не `tsc` по `src/`.** Сборка типизирует
и `scripts/` тоже, и на Vercel падает именно она. Дважды ломал деплой скриптом
проверки: он работал под `tsx`, который типы не смотрит, и проходил мимо
беглого взгляда на `src/`.

**Дату дня считает клиент.** Никаких `current_date`, `now()` и `toISOString()`
для определения дня - часовой пояс базы UTC. Использовать `src/lib/date.ts`.
