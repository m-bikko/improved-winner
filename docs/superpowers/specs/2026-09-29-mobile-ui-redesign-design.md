# Мобильный редизайн UI - спек

Дата: 2026-09-29. Статус: согласовано («делай как хочешь»).

## Цель

Приложением пользуются двое, каждый день, с телефона (PWA на экране «Домой»).
Частые действия - в меньше тапов, состояние дня читается с одного взгляда,
вид тёплый и личный, а не админка. Вес бандла больше не ограничение.

Частота по базе за 30 дней: дневник 310 записей, «Думаю о тебе» 42,
«Как ты» 35, взвешивание ежедневно; темы 4, задачи 5.

## Неизменное

- Функции, данные, схема БД, RLS.
- Три языка (ru/en/kk) - каждый новый ключ во все три.
- Без эмодзи, иконки lucide.
- Цвета данных (`--c-protein/fat/carbs`, `--c-series-*`, `--c-chart`,
  `--c-danger`, `--c-track`) - проверены валидатором, не трогать.
- iOS-решения: клавиатура над шторкой (`useKeyboardInset`), safe-area,
  поля дат, `@layer base` для сбросов, `font-size >= 16px` у полей.
- `BodyChart.tsx` не трогаем.

## Навигация

- Бургер удаляется. Внизу стеклянная панель вкладок:
  **Сегодня · Дневник · Как ты · Профиль · Ещё**.
- «Ещё» - шторка с сеткой плиток: Темы, Задачи, Продукты, Цикл, Даты,
  Вишлист, Год в цифрах, Уведомления; внизу «Выйти». Вкладка «Ещё» активна,
  когда открыт любой её раздел.
- Шапка: заголовок крупным акцентным шрифтом, справа обновление и действие
  экрана. На вложенных маршрутах (`/topics/:id`, `/foods/:id`, `/foods/new`,
  `/cycle/report`, `/cycle/library`, `/month`, `/year`, `/notifications`)
  слева кнопка «назад».
- Панель прячется, когда открыта клавиатура (иначе она едет над ней на iOS).
- Контент получает нижний отступ под панель: `pb-tabbar` = высота панели + safe-area.

## Визуальный язык

- Шрифт заголовков и крупных чисел: Nunito (variable, cyrillic-ext -
  все казахские буквы), локально через `@fontsource-variable/nunito`.
  Основной текст - системный.
- Поверхности: карточки без `ring-1 ring-line`. Светлая тема - мягкая тень
  `shadow-card`; тёмная - ступень светлоты + едва заметная внутренняя линия.
  Радиус карточки 24px (`rounded-3xl`), строк/полей 16px.
- Фон приложения чуть теплее, с мягким розовым сиянием у верха на главной.
- У каждого раздела свой тон значка (`IconBadge`): мягкая заливка + цветная
  иконка. Тона разделов - только для значков, не для данных.
- Акцент остаётся розовым `--c-accent`.

## Компоненты (`src/ui/`)

| Компонент | Что делает |
|---|---|
| `Card` | поверхность с тенью, `as` = section/div/Link, `pressable` - пружинное нажатие |
| `Segmented` | переключатель с ездящей подложкой (motion `layoutId`); заменяет 6 копий |
| `Fab` | плавающая «+», стоит над панелью вкладок |
| `Chip` | выбираемый чип, выбранный залит тоном акцента |
| `ListGroup` / `ListRow` | сгруппированный список в духе iOS: иконка, текст, хвост, шеврон |
| `IconBadge` | цветная подложка под иконку раздела |
| `SectionTitle` | подпись группы над карточками |
| `Sheet` | ручка, свайп вниз закрывает, пружинное появление, клавиатура как прежде |
| `Button` | те же варианты + `soft` (тон акцента), пружинное нажатие |

## Движение

`motion` (`motion/react`). `MotionConfig reducedMotion="user"`. Пружинное
нажатие, подложка вкладок и сегментов по `layoutId`, шторка по пружине,
лёгкое появление экрана при смене вкладки. Никаких бесконечных анимаций.

## Экраны

- **Сегодня**: приветствие по времени суток + дата + два аватара пары;
  крупная «Думаю о тебе»; быстрые действия (еда, отметиться, взвеситься);
  «Как мы» - чипы с иконками состояний у обоих; «Еда» - мини-кольцо и полоски
  Б/Ж/У; остальные плашки на `Card` с `IconBadge`.
- **Дневник**: переключатель дня как капсула; сводка с кольцом на `Card`;
  приёмы пищи без внутренних рамок, «Добавить» - заметная кнопка тона акцента.
- **Как ты**: чипы на `Chip`, «Сохранить» прилипает к низу над панелью;
  прошлые дни - компактные карточки с чипами.
- **Профиль**: «Взвеситься» - главная кнопка; настройки - `ListGroup`.
- **Остальные**: переход на общие компоненты, FAB над панелью.
- **Вход**: тёплый фон с сиянием, карточки-аватары, PIN-пад на новых поверхностях.

## Проверка

`pnpm build`; скриншоты 390x844 каждого экрана, светлая и тёмная тема;
все три языка без обрезаний; клавиатура над шторкой не сломана.

## Порядок работ

1. Зависимости, токены, шрифт, `MotionConfig`.
2. Компоненты `src/ui/`.
3. Оболочка: панель вкладок, «Ещё», шапка с «назад», удаление бургера.
4. Сегодня, Дневник, Как ты, Профиль, Вход.
5. Остальные экраны (можно параллельно подагентами - по файлам без пересечений,
   i18n-ключи добавляет только главная сессия).
6. Скриншоты, сборка, вики, коммит.
